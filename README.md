# DARSYNT Website

Статический сайт-портфолио бренда DARSYNT (Software • Games • Apps).
Чистые HTML / CSS / JavaScript, без сборки, без зависимостей, без серверной части. Совместим с GitHub Pages.

## Запуск локально

Нужен Python 3 (или любой статический сервер):

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Откройте http://localhost:8080/

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Разметка, SEO, Open Graph, JSON-LD |
| `css/styles.css` | Стили, палитра бренда, адаптив, reduced-motion |
| `js/i18n.js` | Словари RU/EN, переключатель, сохранение языка (`localStorage`) |
| `js/main.js` | Меню, подсветка разделов, анимации появления, фон hero (canvas) |
| `assets/` | `favicon.svg`, `og-image.png` |
| `robots.txt`, `sitemap.xml` | SEO |
| `.nojekyll` | Отключает Jekyll на GitHub Pages |

## Визуальные элементы (WEB-2)

- Hero: двухколоночная композиция; справа инлайн-SVG (изометрические платформы, кристалл, световые линии). Графический знак бренда не используется.
- Фон hero: canvas-сеть узлов со световыми импульсами + CSS-сетка «пол». Останавливается вне экрана, на скрытой вкладке и при `prefers-reduced-motion`.
- Карточки проектов: оригинальная абстрактная графика (CSS/SVG), это не скриншоты продуктов. LED — голубая пиксельная сетка, NDI — синяя сеть и сигналы, Stage — фиолетовая ферма и лучи. Анимации включаются при наведении.
- «О нас»: четыре направления с единым стилем линейных иконок. «Контакты»: иконки GitHub и Telegram (inline SVG, без внешних загрузок).
- Адаптив проверен: 1366×768, 1920×1080, 2560×1440, смартфон 375 px.

## Как менять

- Тексты: добавляйте ключи в оба словаря в `js/i18n.js` и атрибут `data-i18n` в HTML.
- Проекты: блоки `.card` в секции `#projects`.
- Шрифт Sora не поставляется в брендките. Сейчас используется системный запасной шрифт.
  Чтобы подключить Sora локально: положите `Sora-Variable.woff2` в `assets/fonts/` и добавьте `@font-face` в начало `css/styles.css`.

## Публикация

- Репозиторий: https://github.com/DARSYNT/darsynt.github.io (public, ветка `main`).
- Сайт: https://darsynt.github.io/ (GitHub Pages, источник: ветка `main`, корень `/`, бесплатно).
- Обновление сайта: коммит и `git push` в `main`, Pages пересоберётся автоматически.
- Все пути в проекте относительные, поэтому сайт работает и в корне домена, и в подпапке.
- Свой домен darsynt.com не подключён, DNS не менялся. При подключении: заменить `https://darsynt.github.io/` на домен в `index.html`, `robots.txt`, `sitemap.xml` и добавить файл `CNAME`.
