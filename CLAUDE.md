# DARSYNT Website — правила проекта

- Язык общения и комментариев в коде: русский.
- Стек: статический HTML/CSS/vanilla JS. Без сборщиков, фреймворков, серверной части.
- Бренд: Cyan #00D4FF, Blue #3B82FF, Purple #9B5CFF, Light #F5F7FF, Dark #0B0F1A; шрифт Sora (с запасным).
- Вместо логотипа/иконки используется текст DARSYNT (юридическая проверка логотипа не завершена).
- Контент: не выдумывать даты релизов, отзывы, метрики, функции; не публиковать исходный код проектов; без вымышленных почт и нерабочих форм.
- Запрещено: платные API/сервисы, аналитика, сбор данных, платежи, секреты, внешние CDN/шрифты.
- Двуязычность: любой новый текст добавлять в RU и EN (`js/i18n.js`).
- Доступность: сохранять prefers-reduced-motion, focus-стили, aria-атрибуты; без горизонтальной прокрутки.
- Оригинальные материалы Brand Kit не изменять (только чтение), другие проекты и репозитории не трогать.
- Хостинг: GitHub Pages, репозиторий `DARSYNT/darsynt.github.io`, ветка `main`, адрес https://darsynt.github.io/ (бесплатно).
- Push в `main` публикует сайт. Делать только по разрешению владельца; без force push.
- Без правок DNS и подключения своего домена, пока владелец не разрешил (canonical/og сейчас указывают на github.io; при подключении darsynt.com заменить в `index.html`, `robots.txt`, `sitemap.xml`).
- Исходники проектов (LED Power & Signal Designer, NDI Diagnostic, Stage Crew Tycoon) в репозиторий не добавлять.
- Локальный просмотр: `python -m http.server 8080 --bind 127.0.0.1`.
- Иллюстрации карточек и hero — оригинальная абстрактная графика (CSS/SVG); не выдавать за скриншоты продуктов и не использовать спорный знак DARSYNT.
- Любая новая анимация должна отключаться в `prefers-reduced-motion` и не грузить CPU (пауза вне экрана).
